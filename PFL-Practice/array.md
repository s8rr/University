### 1. Write a C program to find the sum of all elements of an array.
```c
#include<stdio.h>

int main(){

    int i,n,a[1000],sum=0;
    scanf("%d",&n);
    // input array
    for(i=0;i<n;i++){
        scanf("%d",&a[i]);
    }
    // calculating sum
    for(i=0;i<n;i++){
        sum+=a[i];
    }
    printf("%d",sum);

}
```
